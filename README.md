### 金正 Zheng Jin · 宏观利率研究

我研究一个问题：**宏观信息在市场价格之外，能给固收组合带来什么增量。**
我的回答：宏观信息要和市场已经反映的预期比，才谈得上增量。

**主要发现**

- **政策意外推动利率**：用利率互换度量的央行政策意外每 1bp，带动 10 年国债 0.62bp（t 5.9），预期之内的部分没有影响。
- **宏观状态择时不灵**：实时概率的 Brier 分数 0.39，比一直猜 50% 还差；确认切换后 6 个月，股票平均反向 5.5%。
- **有增量的是期权**：预测固收+ 组合下个月的波动，期权隐含波动让样本外 R² 提高 5.5%，宏观变量都没有增量。
